# Architecture
AI decides · code verifies · PostgreSQL remembers · workers execute · n8n orchestrates · humans can override · gates can stop publication.
**15 modular workflows** (never merged), hand-off through the `jobs` table (state machine: created/queued/running/waiting/completed/failed/retrying/blocked/cancelled/dead_letter) and a webhook allowlist (`job_type_config`) — no workflow-id coupling, so import/update is safe. `01` master claims one job per tick (`ca_claim_job`: concurrency, CPU/RAM/disk limits, circuit breakers, pause) and calls the worker webhook.
Pipeline: `02 Trend → 03 Discovery (authorized creators only) → 04 Rights → 05 Policy (fetch official pages, cache, force-refresh) → 06 OpenShorts clipping (signed webhook) → 07 Packaging → 15 Technical QA + thumbnail → 08 Approval/autonomy gate → 09 Scheduler → 10 Publishing (final gate + idempotent adapters) → 11 Analytics/Earnings`. Support: `12 Supervisor`, `13 Error handler`, `14 Notifications (Gmail)`.
**Hard gates (deterministic SQL):** `ca_rights_gate`, policy assessment + human review (`ca_policy_review`), quality, technical QA, `ca_autonomy_gate` (automatic mode), `ca_platform_account_problem`, and `ca_publish_gate` run immediately before every upload (latest approved version, approval record, rights, policy incl. staleness, QA, platform account, adapter verified, auth circuit, schedule due, duplicate).
**Publication safety:** a schedule is `published` only with a confirmed platform post id. started/processing/ambiguous → human reconciliation; failed → bounded retry on the same row; upload timeouts are classified AMBIGUOUS. **Recovery ladder:** retry → backoff → fallback model → requeue → dead letter/human; circuit breakers per integration, model provider and channel auth.
**Layout:** `workflows/` (generated), `database/` (one authoritative definition per SQL function; `consolidate_sql.py --check`), `workers/`, `deployment/`, `config/`, `source/` (generator + validators + real-n8n harness).
**Not built:** read API/frontend, Google Drive backup, semantic visual QA, IG/FB publishing, YouTube Analytics (watch time/retention) and automatic revenue retrieval.
