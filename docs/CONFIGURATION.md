# Configuration — everything is data (table `settings`, `channels`, `platform_accounts`, `models`, `authorized_creators`)
**Global (`settings`, JSON values):** `timezone`, `max_concurrent_video_jobs` (1), `max_concurrent_light_jobs` (3), `max_cpu_load` (85), `max_ram_usage` (85), `min_free_disk_gb` (8), `system_paused`, `force_manual_approval`, `default_posts_per_day` (2), `n8n_webhook_base`, `openshorts_base_url`, `qa_worker_url`, `notify_email`, `policy_source_urls`, `policy_refresh_days` (14), `block_on_stale_policy` (true), `publish_requires_visual_qa` (true), `auto_requires_visual_qa` (true), `require_thumbnail` (false), `youtube_default_privacy` ("private"), `max_publish_attempts` (4), `stuck_job_minutes` (90; waiting jobs ×4), `stuck_publish_minutes` (15), `max_hashtags` (5), `enable_cloud_models` (false), `adapter_verified_youtube` (true) / `_instagram` / `_facebook` (false), `retention_*_days` (used by retention.ps1), `public_media_base_url` (Instagram only).
**Per channel (`channels`):** `name, niche_id, platforms[], autonomy_mode (manual|automatic), rights_required, monetization_review_required, posts_per_day (NULL = default), preferred_windows [{"start":"HH:MM"}], min_gap_minutes, clip_min_seconds, clip_max_seconds, quality_threshold, timezone, rules{banned_phrases, max…, youtube_category_id, youtube_region, youtube_privacy, auto_windows}`.
**Per platform (`platform_accounts`):** one row per channel+platform, `enabled`, `external_account_id` (REQUIRED for instagram/facebook), `credential_ref` (name only, never a secret). No row → nothing is scheduled or published (fail closed).
**Rights registry (`authorized_creators`):** discovery only searches creators listed here. **Models (`models`):** provider, model, `priority` (lower = tried first), `is_local`, `enabled`; quotas in `model_quotas`.
Changes take effect on the next job (no restart). Environment/secrets live in `config/.env` and n8n credentials only.
