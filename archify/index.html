System Overview & Ingress Perimeter

The Content Automation Platform organizes content production across three operational tiers: an operator-facing CoreUI dashboard served by an Express BFF API (port 3000), 16 decoupled n8n workflow engines (port 5678) acting as distributed state machines, and a specialized background worker tier coordinating video assembly (FFmpeg), audio synthesis, and visual quality assurance.

01. Decoupled State Machine Orchestration

Instead of a monolithic backend worker, business processes are partitioned into 16 discrete n8n workflow definitions. Each workflow maintains an independent error-handling boundary, executes idempotent state mutations, and delegates heavy media compute to isolated Node.js child processes.

02. Pessimistic Lease Locking & Concurrency

High-throughput distributed media generation requires strict concurrency control. The PostgreSQL database uses sequential migrations to define a resilient job queue with row-level locks (SELECT FOR UPDATE SKIP LOCKED) and 30-second worker heartbeats to guarantee at-most-once execution.

03. AI Provider Resiliency & Quota Circuit Breaker

Procedural script generation leverages Groq's high-speed Llama 3.3 70B model for primary synthesis. When rate limits (HTTP 429) or service outages (503) occur, requests automatically fail over to Google Gemini 2.5 Pro. If all providers exhaust quotas, the circuit breaker opens into a 60-second cooldown.

Operational Boundaries & Production Disclosures

⚠️ Honest Engineering Disclosures & Environment Assumptions

To ensure complete integrity in technical recruitment and architectural evaluations, the following boundaries must be explicitly noted:

  • Windows Platform Dependency: Audio synthesis currently invokes Windows SAPI TTS via native PowerShell sub-processes (workers/original_generator.js). Production Linux containerization requires swapping to Piper TTS or an external TTS API.
  • Live Credentials Scope: In accordance with security preflights, live YouTube OAuth tokens and paid Groq/Gemini API keys are not stored in repository configuration. Production deployment requires external secrets injection via Docker environment or HashiCorp Vault.
  • FFmpeg Binary Dependency: Media assembly and QA analysis require FFmpeg 6.0+ installed and discoverable on system PATH.
  • No Unbounded Concurrency: Concurrency is intentionally capped by database connection pool sizing (default 20 connections) to avoid overwhelming local CPU during media encoding.
